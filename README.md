💧 H2ome — Cisterna Inteligente 2050

Sistema inteligente de monitoramento e controle automatizado de níveis de água em cisterna e caixa-d’água, desenvolvido com foco em sustentabilidade, eficiência hídrica e automação residencial.

📌 Sobre o projeto

O H2ome é um projeto de engenharia que propõe uma solução automatizada para o gerenciamento de água, utilizando sensores de nível, controle eletrônico e uma bomba para realizar a transferência de água da cisterna para a caixa-d’água.

O sistema monitora os níveis de água e realiza ações automáticas para evitar o funcionamento inadequado da bomba e facilitar o acompanhamento do abastecimento.

🎯 Objetivos

* Automatizar o abastecimento da caixa-d’água.
* Monitorar os níveis de água da cisterna e da caixa.
* Evitar o funcionamento da bomba quando não houver água suficiente.
* Promover o uso consciente e eficiente dos recursos hídricos.

⚙️ Componentes e tecnologias

* 3 sensores de nível do tipo boia;
* Sistema de controle eletrônico;
* Bomba d’água;
* Display LCD;
* LED vermelho para sinalização;
* Interface de monitoramento IoT.

🔄 Funcionamento do sistema

O projeto utiliza três sensores:

* Sensor 1: identifica quando a cisterna está quase vazia.
* Sensor 2: identifica quando a cisterna possui água suficiente.
* Sensor 3: identifica quando a caixa-d’água está cheia e desliga a bomba.

A bomba realiza a transferência de água da cisterna para a caixa-d’água, respeitando as condições identificadas pelos sensores.

O display LCD apresenta alertas sobre os níveis de água, enquanto o LED vermelho sinaliza a condição de nível baixo na caixa.

🌐 Monitoramento IoT

O projeto também conta com uma interface web para acompanhamento do sistema, integrando automação e Internet das Coisas (IoT).

🏗️ Desenvolvimento

O desenvolvimento envolveu:

* Planejamento e montagem do protótipo físico;
* Desenvolvimento da lógica de automação;
* Integração dos sensores e atuadores;
* Desenvolvimento da interface IoT;
* Modelagem do layout no AutoCAD;
* Testes e ajustes de funcionamento.

🌱 Impacto e sustentabilidade

O H2ome está alinhado ao Objetivo de Desenvolvimento Sustentável 6 (ODS 6) — Água Potável e Saneamento, incentivando soluções tecnológicas para o uso eficiente da água.
